# MY ALICE — инструкция по запуску

Это стартовый проект навыка для Яндекс Диалогов и отдельной веб-панели.

## Что умеет проект

- Принимает запросы навыка на `POST /alice`.
- Отвечает на свободные вопросы через OpenAI Responses API.
- Сохраняет настройки цвета, яркости, темы и предпочтения голоса.
- Даёт веб-панель на `/` с RGB-индикатором, темами, голосами браузера и чатом с ИИ.
- Проверка сервера: `GET /health`.

## Важно про ограничения

Навык не может заменить Алису, изменить системный голос Яндекса или управлять физическим световым индикатором Яндекс Станции. Цвет и яркость относятся к индикатору веб-панели. Выбор голоса в панели использует голоса, доступные браузеру/устройству. В ответах навыка голос определяется настройками озвучивания Яндекс Диалогов.

## Требования

- Node.js 20 или новее.
- OpenAI API key с доступом к выбранной модели.
- Для публикации навыка — сервер с публичным HTTPS URL.

## Локальный запуск

1. Распакуйте архив.
2. Установите Node.js 20+.
3. В папке проекта выполните:

   ```bash
   npm install
   ```

4. Скопируйте `.env.example` в `.env`.
5. В `.env` укажите `OPENAI_API_KEY` и модель, доступную вашему API-аккаунту.
6. Запустите:

   ```bash
   npm start
   ```

7. Откройте `http://localhost:3000`.

Без API-ключа панель откроется, но ИИ будет сообщать, что он не подключён.

## Подключение к Яндекс Диалогам

1. Разместите проект на сервере с HTTPS.
2. В консоли разработчика Яндекс Диалогов создайте навык.
3. В настройках webhook/backend укажите `https://ВАШ-ДОМЕН/alice`.
4. Используйте тестирование навыка в консоли.
5. Для кнопки открытия панели задайте `PANEL_URL=https://ВАШ-ДОМЕН` в `.env`.

Точные названия полей интерфейса Яндекса могут меняться. Сверяйтесь с актуальной документацией Яндекс Диалогов.

## Команды навыка

- «Настройки»
- «Синий индикатор»
- «Фиолетовый индикатор»
- «Красный индикатор»
- «Зелёный индикатор»
- «Женский голос»
- «Мужской голос»
- «Обычный голос»
- «Яркость 60»
- «Светлая тема»
- «Тёмная тема»
- Любой обычный вопрос — передаётся ИИ.

## Где хранятся настройки

Файл `data/settings.json` создаётся автоматически. Сделайте резервную копию этой папки при переносе сервера.

## Перед публикацией обязательно

Этот архив — рабочая стартовая заготовка, а не готовый защищённый публичный сервис. Перед открытием в интернете:
- добавьте авторизацию для веб-панели и API настроек;
- добавьте rate limiting и лимиты расходов на ИИ;
- настройте HTTPS;
- не публикуйте `.env`;
- настройте резервное копирование `data/`;
- проверьте актуальный протокол и требования Яндекс Диалогов.

`PANEL_URL` и `OPENAI_MODEL` должны быть настроены под ваш домен и ваш API-аккаунт.
